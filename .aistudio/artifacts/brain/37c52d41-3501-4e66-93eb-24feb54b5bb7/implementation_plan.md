# بازطراحی جامع و مدرن پنل مدیریت و راه‌اندازی سرور (ServerPanel.hta)

این طرح، نقشه راه بازطراحی کامل رابط کاربری، سبک بصری، آیکون‌گرافی و بهینه‌سازی فنی پنل مدیریت و اجرای سرور ویندوزی (`ServerPanel.hta`) را با تم روشن، مینیمال، اداری و آیکون‌های خطی وکتور ارائه می‌دهد.

---

### تصمیمات نهایی و نیازمندی‌های تأییدشده کاربر

> [!IMPORTANT]
> بر اساس پاسخ‌های دقیق کاربر در مرحله مصاحبه اولیه، تصمیمات زیر مبنای بازطراحی قرار دارند:
> - **سبک و تم بصری**: تم روشن اداری و مینیمال با حاشیه‌های ظریف مویی (`#f8fafc` و `#ffffff` با بوردرهای `slate-200` و تایپوگرافی خوانای فارسی و فونت وزیرمتن).
> - **سیستم آیکون‌گرافی**: جایگزینی کامل تمامی ایموجی‌های کنونی با آیکون‌های برداری وکتور SVG خطی (Linear Vector SVGs) با تناسب استانداردهای مدرن پنل‌های سازمانی.
> - **ساختار چیدمان و معماری دیداری**: داشبورد یکپارچه با ساختار تب‌بندی حرفه‌ای برای کنترل سرور، نظارت بر لاگ‌ها و ترمینال، وضعیت شبکه و آی‌پی، و ابزارهای نگهداری پایگاه‌داده و مخزن.

---

## ۱. نمای کلی سیستم و اهداف طرح (Overview & Core Concept)

### هدف و زمینه کاربرد
فایل `ServerPanel.hta` یک برنامه بومی ویندوز بر پایه HTML Application (HTA) است که به مدیر سیستم، حسابدار یا کاربر نهایی اجازه می‌دهد با یک کلیک و بدون نیاز به ورود به محیط خط فرمان سیاه (CMD):
1. سرور توسعه (`npm run dev`) و سرور عملیاتی (`npm start`) را به صورت فرآیند مخفی پس‌زمینه اجرا و پایش کند.
2. پورت ۳۰۰۰ و پروسه‌های مشغول را در صورت بروز تداخل یا فریز شدن، به صورت درخت پروسه (`taskkill /F /T`) متوقف و آزاد کند.
3. پروب‌های سلامت دوره‌ای (`/api/health`) را ارسال و وضعیت آنلاین/آفلاین و زمان آپ‌تایم را نمایش دهد.
4. آی‌پی‌های فعال شبکه محلی (LAN) را از طریق WMI شناسایی کرده و لینک اتصال موبایل‌ها، تبلت‌ها و صندوق‌ها را با دکمه کپی فوری فراهم کند.
5. فایل‌های مهم سیستم و دیتابیس را در پوشه بکاپ فشرده/کپی کند و ابزارهای نگهداری شامل `git pull`، `npm install`، `npm run build` و `npm run lint` را مدیریت نماید.

### ارتقای تجربه نسبت به نسخه قبلی
- نسخه فعلی از پس‌زمینه بسیار تیره، رنگ‌های نئونی متراکم و ایموجی‌های نامتجانس استفاده می‌کرد.
- نسخه جدید با تم روشن مدرن اداری، تایپوگرافی منسجم، آیکون‌های وکتور خطی سبک Lucide/Heroicons، تب‌های فوق‌العاده نرم و خوانا، مانیتورینگ متمرکز و کنسول ترمینال شیک با کنتراست ارگونومیک بازطراحی می‌شود.

## ۲. تجربه کاربری و طراحی بصری (User Experience & Visual Design)

### الف. پالت رنگی و استایلینگ (Light Minimal Enterprise)
- **پس‌زمینه اصلی (Canvas)**: خاکستری روشن ملایم (`#f8fafc` / Slate-50) برای کاهش خستگی چشم.
- **کارت‌ها و پنل‌های کاری (Surfaces)**: سفید یکدست (`#ffffff`) با خطوط حاشیه فوق‌العاده ظریف (`1px solid #e2e8f0`).
- **رنگ‌های کنترلی و اکشن (Actions)**:
  - آبی نفتی و سلطنتی (`#2563eb` / `#1d4ed8`) برای اکشن‌های اصلی و مرورگر.
  - سبز زیتونی/زمردی اداری (`#059669` / `#10b981`) برای استارت سرور و وضعیت آنلاین.
  - قرمز مرجانی تیره (`#dc2626` / `#b91c1c`) برای دکمه‌های خطر، بستن سرور و پروسه‌ها.
  - کهربایی متین (`#d97706` / `#b45309`) برای ری‌استارت و آزادسازی پورت.
  - سرمه‌ای اداری (`#0f172a`) برای تیترها، آیکون‌ها و متون اصلی.
- **کنسول ترمینال لاگ‌ها**: محفظه ترمینال با سبک مدرن اداری مهندسی: زمینه تیره خاکستری زغالی عمیق (`#0f172a`) با متون مونو فونت با رنگ روشن کرم-سبز زمردی خوانا (`#34d399` و `#e2e8f0`)، بدون چشمک‌زدن‌های زننده، با قابلیت تغییر اندازه و اسکرول نرم.

### ب. آیکون‌گرافی وکتور SVG درون‌خطی (Inline Vector SVGs)
تمامی آیکون‌ها به صورت توابع تولیدکننده یا کدهای بهینه SVG خطی با `stroke-width="1.8"`، اندازه استاندارد ۱۸×۱۸ و ۲۰×۲۰ پیکسل پیاده‌سازی می‌شوند:
- سرور و سخت‌افزار (Server / HardDrive / Cpu)
- اجرای فرآیند (Play / CirclePlay)
- توقف امن (Square / OctagonX)
- راه‌اندازی مجدد (RotateCw / RefreshCw)
- شبکه و وای‌فای (Globe / Wifi / Share2)
- پایگاه‌داده و نسخه پشتیبان (Database / Save / FolderArchive)
- مرورگر و لینک (ExternalLink / Compass)
- کپی سریع (Copy / Check)
- ابزارهای عیب‌یابی (Wrench / Terminal / GitPullRequest / Package / ShieldCheck / Trash2)

### ج. ساختار چیدمان و سازمان‌دهی صفحه (Layout Architecture)
صفحه در قالب پنجره HTA با ابعاد بهینه‌سازی‌شده استاندارد (۱۲۰۰ در ۸۰۰ پیکسل و وسط‌چین خودکار در مانیتور) شامل سه بخش اصلی است:
1. **نوار هدر بالا (Top Header Bar)**:
   - لوگوی اختصاصی و عنوان برند سیستم با تایپوگرافی تمیز.
   - وضعیت زنده سرور (با برچسب متنی واضح «سرور متوقف است» یا «سرور فعال و در حال پاسخگویی است»).
   - کارت‌های آماری کلیدی (زمان پایداری سرور Uptime، آی‌پی شبکه محلی LAN IP، و وضعیت Health Probe).
   - دکمه‌های دسترسی فوری: ورود به نرم‌افزار با Localhost و ورود از طریق آی‌پی شبکه.
2. **ناوبری تب‌های اصلی (Segmented Control Tabs)**:
   - تب ۱: **راه‌اندازی و کنترل سرور** (Dev Mode, Production Mode, Stop, Restart, پورت و تنظیمات دسترسی).
   - تب ۲: **کنسول و مانیتورینگ بلادرنگ لاگ‌ها** (نمایش لحظه‌ای خروجی سرور، فیلتر خطایابی، کپی لاگ، ذخیره در فایل، پاک‌سازی).
   - تب ۳: **شبکه و اتصال دستگاه‌ها** (آدرس شبکه محلی، راهنمای اتصال تبلت/موبایل، دکمه کپی آدرس، آزادسازی پورت).
   - تب ۴: **پایگاه‌داده و ابزارهای نگهداری** (پشتیبان‌گیری دستی، باز کردن پوشه پروژه و بکاپ، DB Push، Git Pull، NPM Install، NPM Build و Lint).
3. **نوار پایینی (Footer Bar)**:
   - نمایش نسخه نود (`node -v`)، پوشه جاری پروژه، و میانبر باز کردن مستقیم پوشه در Windows Explorer.

## ۳. تصمیمات کلیدی فنی و سازگاری با HTA و ویندوز

### ۱. سازگاری کامل با موتور اجرای HTA مایکروسافت
- فایل `ServerPanel.hta` با تگ `<meta http-equiv="X-UA-Compatible" content="IE=edge">` اجرا می‌شود که از استانداردهای مدرن CSS Flexbox، CSS Grid، رنگ‌های متغیر CSS، و آیکون‌های وکتور استاندارد SVG درون کد HTML به صورت کامل پشتیبانی می‌کند.
- برای جلوگیری از هرگونه تداخل با نسخه‌های مختلف ویندوز (Windows 10, Windows 11, Windows Server)، تمام آیکون‌ها مستقیماً به صورت رشته‌های SVG داخل فایل قرار می‌گیرند تا بدون نیاز به اینترنت یا فونت‌های خارجی نیز با وضوح بالا (Crisp 4K/Retina) نمایش داده شوند.

### ۲. حفاظت از منطق فرآیندها و اسکریپت‌های ActiveX
تمامی توابع حیاتی و ایمن فعلی حفظ و ساختاربندی تمیز خواهند یافت:
- شیء `WScript.Shell` برای اجرای دستورات کامند `npm run dev`، `npm start` و سایر ابزارها به صورت مخفی (`windowStyle = 0`).
- شیء `Scripting.FileSystemObject` برای ساخت لاگ، خواندن افزایشی لاگ بدون قفل کردن فایل، ایجاد پوشه بکاپ و کپی فایل‌های اصلی نرم‌افزار.
- اتصال WMI (`Win32_NetworkAdapterConfiguration`) برای استخراج خودکار آی‌پی محلی اترنت یا وای‌فای کارت شبکه.
- درخواست ناهمگام `Microsoft.XMLHTTP` برای ارزیابی سلامت مسیر `/api/health`.
- اسکریپت خروج امن و خاتمه پروسه‌ها بر اساس پورت از طریق فایل موقت داس در `%TEMP%`.

### برنامه گام‌های پیاده‌سازی پس از تأیید
1. **طراحی کتابخانه آیکون‌های SVG خطی**: تعریف مجموعه‌ای از آیکون‌های وکتور تمیز و سبک برای تمامی دکمه‌ها، برچسب‌ها و کارت‌ها.
2. **طراحی استایل‌شیت تم روشن اداری**: تنظیم متغیرهای رنگی، حاشیه‌های مویی، کارت‌های تفکیک‌شده سفید با سایه‌های نرم، استایل تب‌های مدرن، و دکمه‌های ارگونومیک با افکت هوور.
3. **بازسازی ساختار HTML داشبورد**: پیاده‌سازی هدر با اطلاعات مانیتورینگ زنده، سگمنت‌های تب‌بندی، چیدمان فرم پورت و آدرس شبکه، و محفظه لاگ‌های کنسول.
4. **تزریق و بهینه‌سازی کدهای اسکریپت**: اطمینان از عملکرد دقیق خواندن لاگ‌ها، زمان‌سنج آپ‌تایم، پروب خودکار سلامت، استارت و استاپ پروسه‌ها و عملیات کپی کلیپ‌بورد.
5. **اعتبارسنجی نهایی**: بررسی کامل ساختار تگ‌های HTA، عدم وجود خطای نگارشی یا جاوا اسکریپت و حصول اطمینان از آماده بودن کامل برنامه جهت بهره‌برداری.
